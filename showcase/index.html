SWECCathon · Mesocosm Benchmark

2048 move selection, judged by Monte Carlo tree search.

MCTS 2048 asks agents to choose the next move from a live 2048 board. The environment computes a rollout-based policy table and grades each action with a non-binary reward that grows for correct streaks and escalates penalties for bad moves.

Environment Context

A compact planning benchmark

Every observation contains the current board, score, legal moves, and an MCTS policy table. The table is produced from numpy/pandas rollouts and gives agents a transparent target: return the rank-1 move whenever possible.

State

4x4 Board

Agents see the full tile grid, max tile, score, empty cells, and valid move list.

Teacher

MCTS Policy

Rollouts estimate value for each legal move, then rank moves by value and mobility.

Reward

Shaped Scalar

Rank-1 moves earn up to +2. Lower-ranked and invalid moves fall as low as -2.
